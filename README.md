# Todo App

A simple, responsive Todo App built with **HTML, CSS, and JavaScript**. It provides a clean, minimal interface for managing daily tasks by allowing users to add new tasks and delete completed or unwanted tasks.

## ✨ Features

- ➕ Add new tasks
- 🗑️ Delete tasks easily
- 🎨 Clean and minimal user interface
- 📱 Responsive design for different screen sizes
- ⚡ Fast and lightweight functionality
- 🧩 Built with vanilla JavaScript

## 🛠️ Technologies Used

- **HTML5** for structure
- **CSS3** for styling and layout
- **JavaScript** for task management and interactivity

## 📂 Project Structure

```text
Todo_App-Project/
├── index.html
├── Todo.css
└── Todo.js
```

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Todo_App-Project.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.
